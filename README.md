# konsolowy-odtwarzacz
Wideo odtwarzacz filmów z youtube bezpośrednio w konsoli 

Program stworzony na Linux Fedora

Instalacja

Aby skrypty się uruchomiły trzeba nadać im uprawnienia chmod +x
```
chmod +x instalka.sh odtwarzacz.sh
```
Następnie można uruchomić skrypt instalacyjny
```
./instalka.sh
```
Po instalacji skrypt jest gotowy do pracy

aby skorzystać z programu należy wywołać go oraz wpisać żądany link do wideo w apostrofach
```
./odtwarzacz.sh '<link do wideo>'
```

W katalogu domowym pojawi się folder o nazwie "wideocon" w którym będą znajdować się pliki wideo po obejrzeniu można je bezpiecznie usunąć
